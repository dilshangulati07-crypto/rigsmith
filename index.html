Three ways to build

01Hands-on

Build by hand

Start from an empty case and fit each part the way you would on a desk: PSU, motherboard, CPU, cooler, memory, storage, graphics card, fans. Then run every cable from the PSU to its port and route it behind the tray.

  • Install order enforced
  • Undo and redo on every step
  • Cable management score
02Automatic

Auto-build

Give a budget in baht, the main use and the case size. A compatible set of parts is picked with the reason for each choice, and the PC assembles itself on screen in the same order as a real build.

  • Gaming, creator, office, AI
  • Playback at 1×, 2×, 4× or skip
  • Save the assembly as video
03Side by side

Compare builds

Put up to three builds next to each other: parts, total price, estimated performance for each workload, power draw and size. Swap a single part to see what it changes before you spend anything.

  • Price per performance
  • Shareable build link
  • CSV and print export
